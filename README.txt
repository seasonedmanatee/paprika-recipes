PAPRIKA → COOKLIST STATIC RECIPE SITE

This folder contains 106 standalone recipe pages with Schema.org Recipe JSON-LD, visible ingredient/instruction lists, and extracted local photos where available.

DEPLOYMENT
1. Publish the contents of this folder to a static web host (e.g. a new public GitHub repository with GitHub Pages enabled).
2. Open the published index.html URL, then open one recipe page.
3. Copy that direct recipe URL into Cooklist > Add a recipe > Import a recipe from the web.
4. Verify imported title, ingredients, instructions, servings and photo before attempting the remaining recipes.

IMPORTANT
- Do not upload the ZIP to a public repository until you are comfortable making the recipe content and images publicly accessible.
- The pages use Schema.org Recipe markup but Cooklist may still reject or incompletely parse custom pages. Test one first.
- This package does not automate Cooklist submissions. Bulk submission should only be built after a successful one-page test.
- The page links use relative paths and are intended to be hosted as a directory tree; do not open the files directly from disk and expect Cooklist to fetch them.
